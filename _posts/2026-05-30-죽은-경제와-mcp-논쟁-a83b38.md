며칠 사이 HN 메인에 "the dead economy theory" 와 "MCP is dead?" 가 거의 동시에 올라왔다. 둘 다 댓글이 수백 개 넘게 달렸고, 둘 다 "끝났다" 라는 단어 하나로 사람들을 끌어모았다. 토픽은 전혀 다른데 프레임이 똑같아서 좀 웃겼다.

먼저 MCP 쪽. MCP — Model Context Protocol, Anthropic 이 작년 말에 던진, LLM 이 외부 도구·데이터에 붙는 방식을 표준화하자는 프로토콜 — 가 벌써 한물갔다는 주장이다. 근거는 대충 이렇다. 어댑터 한 번 만들면 어디든 붙는다는 약속에 비해, 실제로는 클라이언트마다 구현이 미묘하게 다르고, 보안 모델은 아직 헐겁고, 큰 회사들은 자기 fork 를 만들고 있다는 것.

내가 MCP 서버를 두어 개 직접 띄워서 Claude Desktop / Cursor 양쪽에 붙여본 인상은 — 죽지는 않았는데, "표준" 이라고 부르기엔 아직 빈틈이 너무 많더라. 같은 tool definition 인데 클라이언트 A 에선 잘 호출되고 B 에선 인자 파싱이 깨진다. 인증·권한 모델은 사실상 "credential 통째로 넘기세요" 수준이라 production 에 그대로 쓰기 무섭고. 그래서 "죽었다" 보단 **"표준이 되기 전에 분기될 위험"** 이 좀 보인다 — 가 더 정확한 진단인 것 같다.

"죽은 경제 이론" 쪽은 결이 다르다. 핵심은 — 기술 혁신은 빨라지는데 실질 성장률·생산성 통계는 왜 안 따라오느냐, 이 둘이 디커플링됐다는 관찰이다. AI 가 코딩을 절반은 대신 해주는데 GDP 그래프는 평행선이다. 댓글은 둘로 갈렸다. "통계가 새 형태의 가치를 못 잡는 것뿐" vs "실제로 성장 엔진이 멎었고 우리가 그걸 AI 자극으로만 가리고 있다."

재밌는 건, 두 글타래에서 나오는 단어들이 비슷하다는 점이다. "표준이 무너졌다", "성장이 멈췄다", "다들 자기 fork 를 만든다", "지표가 거짓말한다". 솔직히 사람들은 시스템이 매끄럽게 굴러가는 이야기보다 **균열이 보이는 이야기**에 훨씬 더 길게 머문다. 댓글 수가 그걸 증명한다.

내가 이 두 글을 같이 본 이유는 사실 단순하다. 한쪽은 내가 매일 만지는 도구의 미래 얘기고, 한쪽은 내 월급의 미래 얘기다. 둘 다 "끝났다" 는 단정이 좀 게으른 진단이라고 생각하지만, 그 단정 덕에 사람들이 모여서 진짜 논점이 굴러간다는 것도 사실이고.

MCP 가 진짜 죽을지, 경제가 진짜 멎었는지는 좀 더 봐야 알 것 같다. 다만 "끝났다" 가 토론을 여는 가장 싼 티켓이라는 건 — 이 두 글타래만 봐도 꽤 확실해 보인다.
