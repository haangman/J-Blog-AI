요즘 Claude Code 쓰다가 'Mythos 1' 이라는 처음 보는 모델명이 슬쩍 떴다는 글이 Reddit r/singularity 에 올라왔다. Claude Code — Anthropic 이 만든 터미널용 코딩 에이전트 — 안쪽 어딘가에 stealth 모델 식별자가 노출됐다는 목격담이다. 진위는 아직 명확하지 않다.

Anthropic 이 이름 안 알리고 새 모델을 어디 끼워 넣는 건 처음이 아니다. 보통 OpenRouter 나 lmarena 같은 모델 비교 사이트에 코드네임으로 슬쩍 올려서 사람들 반응을 살피고, 한참 뒤에야 정식 이름으로 발표하는 패턴. OpenAI 도 작년 'gpt2-chatbot' 같은 식으로 떠본 적 있다. 그래서 Mythos 1 도 비슷한 흐름이라고 보는 사람이 많다.

근데 재밌는 건 이게 단순 떡밥이 아니라, 거의 같은 시기에 테런스 타오 — UCLA 수학과의 그 필즈상 받은 사람 — 가 자기 GitHub 에 "Claude Code 로 증명을 다듬어봤다" 는 글을 올렸다. 제목이 "Golfing and stylistically aligning a proof using Claude Code". 본인 표현으로는 "Certified Hood Classic" 시리즈 또 한 편.

여기서 'golfing' 이라는 표현이 좀 웃긴데, 코드 골프 — 같은 결과를 더 짧은 코드로 줄여 쓰는 일종의 놀이 — 의 수학판 비유다. 이미 맞게 쓴 증명을 더 짧고 우아하게 다듬는 작업.

타오의 글을 보면 LLM 한테 수학을 "처음부터 시켰다" 가 아니다. 본인이 쓴 증명을 더 깔끔하게 다듬는 작업에 도구로 쓴 거다. 표기를 통일하고, 보조정리 순서를 바꾸고, 군더더기를 잘라내는. 사람 수학자가 페어 프로그래밍하듯 옆에 LLM 을 둔다.

이게 시사하는 게 있다. 일반인이 보기엔 "LLM 이 필즈상 받은 사람이랑 수학 한다고?" 인데, 실제 내용은 훨씬 협소하다. 새 정리를 만든 게 아니라 이미 있는 증명의 스타일 정렬. 그래도 무시할 일은 아니다. 수학 글쓰기는 결국 텍스트 작업이고, 그중에서도 가장 까다로운 일관성 요구가 걸리는 영역이라. 거기서 Claude Code 가 보조 역할을 맡는다는 건 단순 코드 리팩터 이상의 신뢰가 쌓이고 있다는 신호로 보인다.

내 환경에서 Claude Code 써본 인상을 솔직히 말하면, 잘 모르는 코드베이스 들어가서 "이 함수 어디서 호출돼?" 같은 거 묻고 받는 답이 체감상 가장 정확해진다. 정답이 안 나오면 차라리 "모르겠다" 고 답하는 빈도도 늘었더라. 자신 없을 때 자신 없다고 말하는 능력 — 이게 production 에 LLM 붙일 때 가장 아쉬웠던 부분이라 작은 변화도 반갑다.

다시 Mythos 얘기로. Anthropic 이 모델 출시 전에 Claude Code 안에서 내부 테스트를 돌린다는 건 공공연한 비밀에 가깝다. 그래서 Mythos 1 이 진짜라면 Opus 다음 세대일 가능성이 높고, 가짜라도 누군가의 dev tools 화면에서 그 문자열이 잡혔다면 어디서 흘러나왔는지 자체가 흥미롭다.

물론 이건 외부 관찰자 시점이고, 실제 내부 프로세스는 다를 거다. 내가 잘못 알고 있을 수도 있다.

두 사건이 가리키는 방향은 결국 비슷하다. Claude Code 가 "개발자 보조 툴" 카테고리를 넘어서 코드, 수학, 글쓰기까지 같은 인터페이스에서 다뤄지는 워크플로 도구로 자리 잡고 있다는 거. Mythos 가 진짜 신모델이든 아니든, 그 안에서 무슨 작업이 가능한지의 범위 자체가 한 달 단위로 넓어지는 중이다.
