요즘 머신러닝 커뮤니티 글들을 죽 훑어보다가 비슷한 결의 불만이 동시에 올라오는 게 보였다. VLM(Vision-Language Model, 사진을 이해하고 텍스트로 답하는 모델 — GPT-4V나 Claude 의 이미지 처리가 다 여기 들어간다) 들이 아직도 고정 크기 patch 의 ViT (Vision Transformer, 이미지를 격자로 잘라 토큰화하는 구조) 를 쓰고 있느냐는 질문이 r/MachineLearning 에 올라왔는데, 댓글 분위기가 "그러게 왜 그런지 모르겠다" 쪽이다.

사실은 연구 쪽에선 가변 patch, content-adaptive 토크나이저 같은 게 진작 나왔다. Perceiver 계열도 있고, Q-Former 같은 cross-attention 리샘플러도 있고. 근데 production 에서 굴리는 큰 모델들은 거의 다 fixed-patch ViT 그대로다.



내 짐작은 단순하다. 학습 파이프라인이 이미 그 위에 산처럼 쌓여 있어서. 데이터 전처리, 분산 학습 코드, eval 셋, 다 fixed-patch 가정으로 짜여 있고 갈아엎으면 몇 주가 그냥 날아간다. 연구가 더 좋다는 걸 알아도 제품 쪽 우선순위가 다른 거다. 이게 좀 웃긴 게, 비슷한 시기에 VLA (Vision-Language-Action, 로봇 제어용으로 VLM 에 행동 토큰을 붙인 모델) 쪽 연구가 포화에 다다른 느낌이라는 얘기, liveness detection (얼굴 인증할 때 진짜 사람인지 합성 영상인지 구분하는 거) 이 deepfake 에 일반화가 안 된다는 얘기, 벤치마크 점수랑 실제 운영 성능이 점점 벌어진다는 얘기가 다 같이 올라왔다.

공통점은 하나다. 모델 구조랑 평가 방식이, 그게 마주칠 실제 환경 변화를 못 따라가고 있다는 거.

벤치마크 얘기로 좀 더 가자면, 내 환경에서도 체감하는 부분이다. 어떤 LLM 이 MMLU 점수가 더 높다고 우리 제품에서 더 좋게 동작하느냐 하면, 그건 거의 별개 문제더라. 우리는 한국어 도메인 데이터로 잡은 자체 eval 셋에서 점수를 따로 본다. 공개 벤치는 학습 데이터에 새고, 우리 도메인은 거의 안 새고. 결국 신뢰할 수 있는 숫자는 자기 도메인 안에서 직접 측정한 것뿐이다.

같은 주에 검색 쪽 글들도 묶여 올라왔다. Kagi 가 저시력 사용자 접근성을 손보고 있다는 글, 뉴스 사이트들이 Internet Archive 의 크롤 접근을 막기 시작했다는 글, 구글이 검색 결과에 광고 슬롯을 더 늘리는 실험을 한다는 글. AI 평가 얘기랑 직접 연결되진 않는데 묶어 보면 결이 비슷하다. 모델이 보는 입력 데이터의 출처가 점점 좁아지고, 그 좁아진 데이터 안에서 평가까지 다 끝내고 있다는 그림.

이게 어떻게 굴러갈진 좀 더 봐야 할 것 같다. 일단 내 쪽에선 자체 eval 셋 키우는 작업부터 우선순위를 올렸다.
